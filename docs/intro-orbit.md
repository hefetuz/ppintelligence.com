# Yörüngeden Darphaneye

Branch: `intro/orbit-mint`. Root opens this concept; `?intro=original` keeps the original available.

The original hero composition, copy and true 3D eight-second coin loop are shared. The second exploration pairs this opening with cool satin-silver hands and a larger, depth-layered orbital material lift; see `hand-art-direction.md`.

## Choreography

- 0–1.1s: six large metallic currencies orbit on a shallow, depth-sorted ellipse.
- 1.1–2.7s: each glyph releases sampled currency grains into a curved inward orbit.
- 2.25–3.37s: grains establish the rim, the coin surface closes inward and the PP seal is struck last.
- 3.45–4.75s: that same coin travels into the hands; the headline begins at 4.42s.

Skip, pause, reduced motion, keyboard interaction, touch release and bounded asset fallback remain available. Glyphs are sampled once per width change. The shared spin integrates velocity instead of interpolating rotation angles, avoiding reverse movement at handoff.
